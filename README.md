# AQ SARAY — отель (концепт)

Концепт сайта гостиницы. Отель, номера, цены и контакты вымышленные. Фото — [Unsplash](https://unsplash.com)
(бесплатная лицензия Unsplash), логотипы чужих отелей на фото замазаны.

**Сайт:** https://iaroslaviskendirov-alt.github.io/aq-saray/

**Стек:** React 19, TypeScript, Vite, Tailwind CSS 4, framer-motion, lucide-react.
Структура в стиле shadcn: компоненты в `src/components/ui`, утилиты в `src/lib`.

## Что внутри
- Поиск по датам: заезд, выезд, гости. Цены всех номеров пересчитываются под выбранные даты,
  пятница и суббота дороже на 15%.
- 5 категорий номеров со слайдером фото (свайп на телефоне), площадью, вместимостью и остатком.
- Окно брони: доп. услуги (завтрак, трансфер, поздний выезд), имя и телефон, расчёт итоговой суммы.
- `telegram-preview.tsx` — макет Telegram-бота: заявка с сайта сразу появляется в чате администратора,
  её можно «подтвердить» кнопкой. Показывает, как работает связка сайт + бот.
- Ресторан, спа, удобства, галерея, частые вопросы, контакты.
- Данные отеля — в `src/data.ts`, расчёт цены — в `src/lib/booking.ts`.

## Запуск
```bash
npm install
npm run dev
```
Публикация — автоматически через GitHub Actions при push в `main`.
